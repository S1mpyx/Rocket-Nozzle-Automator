# ⚠️ Информация об антивирусах

Исполняемый файл **Rocket Nozzle Automator.exe** может определяться некоторыми антивирусными системами как подозрительный.

Основные причины этого:

- программа собрана при помощи **PyInstaller**;
- отсутствует цифровая подпись;
- файл новый и имеет небольшое количество загрузок;
- некоторые антивирусы используют эвристический анализ и могут выдавать ложные срабатывания (False Positive).

Большинство известных антивирусных систем не обнаруживают вредоносной активности.

При желании любой пользователь может самостоятельно проверить файл через **VirusTotal**.

# ⚙️ Принцип работы

В программе реализована разработанная автором **индексная система ввода данных**.

Пользователь вводит только основные характеристики топлива.

После этого программа автоматически:

- анализирует параметры топлива;
- рассчитывает геометрию сопла;
- вычисляет основные характеристики;
- строит двумерную (2D) геометрию сопла.

Такой подход значительно упрощает процесс расчётов по сравнению с ручным вычислением большого количества параметров.
