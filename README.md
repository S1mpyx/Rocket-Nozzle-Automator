# ⚙️ Nasıl Çalışır?

Rocket Nozzle Automator'da geliştirilen **İndeks Tabanlı Giriş Sistemi** sayesinde kullanıcı onlarca parametreyi tek tek girmek zorunda kalmaz.

Kullanıcı yalnızca gerekli yakıt özelliklerini girer.

Program otomatik olarak;

- Yakıt parametrelerini işler
- Nozzle geometrisini oluşturur
- Performans hesaplarını gerçekleştirir
- Sonuçları 2 Boyutlu (2D) nozzle geometrisi olarak gösterir

Bu yaklaşım klasik manuel hesaplamalara göre daha hızlı ve daha kullanıcı dostudur.

# 📌 О проекте

Rocket Nozzle Automator — образовательное приложение на Python для автоматического анализа сопел Лаваля, применяемых в жидкостных ракетных двигателях.

Проект создан исключительно в образовательных целях.

При разработке использовались открытые инженерные материалы, научные публикации и общедоступные расчётные методы.

Архитектура программы, система автоматизации, пользовательский интерфейс и индексная система ввода разработаны автором проекта.

Проект предназначен для:

---

# ⚙️ Принцип работы

Разработанная **индексная система ввода** позволяет пользователю вводить только необходимые характеристики топлива.

После этого программа автоматически:

- рассчитывает геометрию сопла;
- проводит анализ характеристик;
- отображает двухмерную модель сопла.
